Undergraduate co-op, internship, and software new-grad postings in **Canada & the United States**.

Boards live in `boards/` and are sorted newest first. Closed applications and anything older than 30 days are removed on sync.

```bash
cd coop-internships
python3 -m pip install requests
python3 main.py sync      # fetch + rewrite boards
python3 main.py readme    # rewrite boards only
```
